# DNS Analysis Evidence

This directory contains evidence demonstrating DNS query monitoring using Sysmon within the Windows SOC monitoring lab.

Sysmon DNS telemetry was configured and validated through the Microsoft-Windows-Sysmon/Operational event log. DNS activity generated by processes on the endpoint was recorded as Sysmon Event ID 22 and reviewed through Windows Event Viewer.

Key telemetry analyzed includes:

- **Sysmon Event ID 22 — DNS Query**
  - Records DNS queries performed by processes on the endpoint.
  - Provides the queried domain name, originating process, query status, and returned results.
  - Allows analysts to associate DNS activity with endpoint processes during an investigation.

DNS telemetry can provide valuable context during security investigations by helping analysts identify unusual domain lookups, correlate network activity with executing processes, and investigate potentially suspicious communications.

During this lab, Event ID 22 telemetry was successfully validated through observed DNS activity on the Windows 11 endpoint.
